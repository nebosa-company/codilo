# Codilo Privacy Policy

**Last updated: 4 November 2026**

Codilo is a local desktop code editor. It does not collect, transmit, sell, or
share personal information.

## What Codilo does not do

- No account or sign-in.
- No telemetry, analytics, advertising, or crash reporting.
- No upload or remote processing of the files and folders you open.
- No plugin marketplace or background indexer.

## Data stored on your device

Settings, session state, recent folders, and interface preferences are stored
locally on your device. They are not sent to Nebosa or any third party.

## Network access

The Microsoft Store build has no external update check; updates are delivered by
Microsoft Store.

The non-Store Windows build includes a manual **Help → New Version** check that
contacts GitHub only when you click it. GitHub may receive standard technical
request data, such as an IP address, under GitHub's privacy statement.

Opening external links or running commands in the integrated terminal can
connect to the internet. Those actions are initiated by you and are governed by
the destination or command you choose. The app includes third-party open-source
components, which do not add tracking.
