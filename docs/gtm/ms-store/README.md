# Microsoft Store screenshots

Ready for Partner Center. All five images are **1920×1080 PNG**, 16:9, and show
the Store build on a clean demo project (`aurora`).

The machine-readable submission manifest is [submission.json](submission.json).

| File | Caption |
| --- | --- |
| `01-editor-explorer-dark.png` | A fast, focused editor: Explorer, tabs, syntax highlighting and the status bar. |
| `02-split-panes-dark.png` | Split panes for editing two files side by side. |
| `03-integrated-terminal.png` | A real terminal inside the editor, opened in the project folder. |
| `04-light-theme.png` | Light theme, Markdown editing and the same uncluttered layout. |
| `05-command-palette.png` | Every action is one search away in the command palette. |
| `06-language-modes.png` | Choose from 35 language modes, from JavaScript and TypeScript to Rust, Go, C/C++, SQL, HTML, CSS and more. |

The screenshots were captured from the app on Windows with a demo React/Vite
project. No customer data, account details or local paths outside the demo
project are visible.

The language-mode picker is shown fully expanded so the complete list is
readable; in the app the list scrolls within the popup.

Partner Center accepts up to 10 screenshots; these five cover the main
differentiators. If more are wanted, useful additions would be Project Metrics
and the interface-language picker.
